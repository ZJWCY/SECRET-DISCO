# SECRET DISCO

**※ 注意：OSの挙動を制御する仕様上、ファイアウォール、セキュリティソフトに誤検知される可能性があります。**

<h3>Unity・C#で作成した3Dレトロ風固定視点アドベンチャーゲーム</h3>

　本作は、テキスト謎解きアドベンチャーゲームであり、自分の大学の卒業制作（ゲームデザイン・開発分野の集大成）となる作品です。
自分の大学の寮をモチーフにしたステージで、プレイヤーはオブジェクトをマウスクリックし、浮かび上がる思い出の中から正しい選択肢を選び、心の迷いを解き明かして寮からの脱出を目指します。

　本作の最大の特徴は、.NET Framework経由でWindows APIを叩くことで実装した『メタ要素』です。例えば、『プレイヤーが長時間正しい選択肢を選べない場合、PCを強制的にスリープさせる』『エンディング曲の再生中にPCの音量をロックする』といったシステム干渉ギミックを盛り込み、ゲームキャラクターの持つ『抑うつ感』をプレイヤー自身にシンクロさせる演出を試みました。

　**※ 上記のOS干渉機能を実装しているため、ファイアウォール、セキュリティソフトに誤検知される可能性があります。**

　本作でも独自に開発した『レトロテレビ風』のポストエフェクトを適用しています。これにより、現実と虚構が入り交じるような、本作の独特かつノスタルジックな世界観をより効果的に演出しています。
 
<h3>操作方法</h3>

- 視点切り替え： キーボードの [A] / [D] キー
- オブジェクトとのインタラクション（調べる）：マウスの左クリック
